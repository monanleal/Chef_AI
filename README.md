# 🍳 Chef AI

</br>

Aplicação web que utiliza inteligência artificial para gerar receitas personalizadas com base nos ingredientes fornecidos pelo usuário.

</br>

🔗 Acesse o projeto: https://chef-ai-receitas.netlify.app/

</br>
</br>

🚀 Funcionalidades
- Geração de receitas com IA a partir de ingredientes informados
- Interface simples e intuitiva
- Respostas rápidas e dinâmicas
- Experiência responsiva para desktop e mobile

</br>
</br>

🛠️ Tecnologias utilizadas
- React
- Node.js
- Tailwind CSS
- API do ChatGPT (OpenAI)

</br>
</br>

💡 Como funciona
O usuário insere os ingredientes disponíveis, e a aplicação utiliza a API do ChatGPT para gerar uma receita completa, incluindo modo de preparo e sugestões.

</br>
